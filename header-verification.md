# Verificação do header contextual

A navegação directa para `/#verano-stay` posiciona o preview na secção do Flat Verano Stay. O header aparece com fundo terracota, texto claro e CTA legível, confirmando que a detecção contextual das secções `verano-stay` e `copacabana` está a aplicar o estado de reserva. O conteúdo do apartamento permanece legível por baixo do header fixo. O mesmo comportamento foi implementado para Copacabana através da lista partilhada de IDs no `Layout.tsx`.
